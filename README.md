# GSI Overlay for Huawei Nova 3i (INE)

**English** | [简体中文](README_CN.md)

# Description
- Enable auto brightness, battery usage data and fix display cutout for Huawei Nova 3i with GSI.

# Usage
- Install module file in Magisk/KernelSU.
- Reboot.
