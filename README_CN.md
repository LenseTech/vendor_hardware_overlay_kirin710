# 适用于Huawei Nova 3i (INE) 的GSI Overlay模块

[English](README.md) | **简体中文**

# 说明
- 在刷入GSI后的华为Nova 3i中启用自动亮度、添加电量详情以及适配刘海。

# 使用方法
- 在Magisk/KernelSU管理器中刷入模块。
- 重启手机。
